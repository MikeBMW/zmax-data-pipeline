# W2-VLA 论文学习笔记 (Z-MAX 应用评估)

> 2026-08-09 · 小芳记录 · arXiv:2608.05369v1
> World-to-Wrist: Task-Conditioned Future Wrist Modeling for Fine-Grained Robot Manipulation

## 核心思想
主视角(World)提供全局任务上下文 + 腕部视角(Wrist)细粒度接触预测，
通过紧凑潜在接口连接，**预测未来腕部潜在特征**作为"未来感知"上下文生成动作。

## 架构
```
世界视角 → VLM → 全局上下文 ─┐
                              ├→ 潜在接口(W2-CoT塑造) → 未来腕部预测器 → 动作生成
腕部视角 → 腕部历史 ─────────┘
W2-CoT: 操作进度/物理转换线索/腕部局部证据 (结构化标注, 训练辅助监督)
```

## 关键性能
- 80Hz 实时动作生成 (推理免CoT)
- LIBERO + RoboTwin 2.0 + 真机 单臂/双臂 均 SOTA
- 细粒度接触敏感操作显著提升

## Z-MAX 契合度 (光模块400G AOI产线)

| W2-VLA | Z-MAX 对应 |
|:---|:---|
| 细粒度接触 | 插拔 ±0.05mm 对准 (SCN_PLUG) |
| 主+腕视角 | 顶部相机 + D405末端相机(wrist) |
| 未来腕部建模 | 插入过程接触力/深度预测 |
| 80Hz | 现推理30-500ms → 10倍潜力 |
| 双臂扩展 | 珞石XMS5单臂 → 后续双臂 |
